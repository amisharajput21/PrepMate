# PrepMate - Placement Preparation Platform

PrepMate is a web application designed to help students prepare for placement tests and technical interviews.

## Features
- User registration and login
- Placement preparation dashboard
- Data Structures and Algorithms (DSA) practice
- Aptitude practice with answer explanations
- Technical interview preparation
- Placement roadmap
- User progress tracking

## Tech Stack
- **Frontend:** React.js, JavaScript, HTML, CSS
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **API:** REST APIs

## Project Structure
- `frontend/` - React frontend
- `demo/` - Spring Boot backend

## How to Run

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
Open the `demo` folder in IntelliJ IDEA, configure your MySQL connection in `application.properties`, and run the Spring Boot application.

## Database
Create a MySQL database named `prepmate` and configure your database credentials in the backend settings.

## Purpose
PrepMate brings DSA practice, aptitude preparation, technical interview topics, and progress tracking together in one platform.
